Retrieval · one pass

Plan once, search once, check once. Done.

Harness · agent loop

Plan, search, check, go again.

Why we care

Real questions take more than one step.

Find a thing, read a fact from it, then search again with that fact. One pass never sees the fact, so it misses everything after step 1. The loop costs more time and money. It earns it when the question has steps.
